Think someone should be added to the database? Post it here — same GitHub-account commenting as player pages, one shared thread for all requests.

Paste a full row copied directly from the stats table (RK, Yr, Ht, Player, Team, Conf, G, Min%, PRPG!, D-PRPG, BPM, OBPM, DBPM, ORTG, D-RTG, USG, EFG, TS, OR, DR, AST, TO, A/TO, BLK, STL, FTR, FC/40, Dunks, Close 2, Far 2, FT, 2P, 3PR, 3P/100, 3P) — it fills name, team, class, height, and the core stats, splits the "makes-attempts" cells, and computes all 12 Advanced Metrics + FGA automatically (they're derivative of these stats, not separate data — same formulas as the original sheet). Position, ranks, availability, and Latino still aren't in this table, so those stay manual.

Paste a season-totals row copied straight from a stats table (Split, Team, League, GP, GS, MIN, PTS, FGM, FGA, FG%, 3PM, 3PA, 3P%, FTM, FTA, FT%, ORB, DRB, TRB, AST, STL, BLK, TOV, PF) — per-40 rates, 2P%, AST/TOV, 3PAr, and FTr are all computed automatically from these totals. The player's name isn't in that table, so enter it separately below.

Bulk Add (multiple players at once)

For a multi-player table (a whole team's stats, not one player's own page). Paste the header row first (from whatever source you're using — column order and which stats are included can vary), then the data rows below it. Columns are matched by name (Name/Player, GP, MIN, PTS, FGM, FGA, FG%, 3PM, 3PA, 3P%, FTM, FTA, FT%, ORB, DRB, AST, STL, BLK, TOV, League, Team...), not by fixed position, so this adapts to different sources. No header row pasted falls back to one default layout.

Export current availability to edit in a spreadsheet, then import the edited file back — this only ever touches the two availability fields, everything else on each player is left alone.
